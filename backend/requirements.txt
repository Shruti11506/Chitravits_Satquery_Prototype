# --- SatQuery agent (app/agent_bridge) --------------------------------------
# The `satquery` package provides the LangGraph agent + remote wrapper clients
# that the agent bridge drives. It is NOT on PyPI.
#
# Its source is VENDORED into this repo at backend/satquery/ (committed so the
# agent implementation is visible for inspection). The Dockerfile copies it to
# /app/satquery and it is imported directly from there -- there is deliberately
# NO active `satquery` requirement line and no pip install, so nothing here can
# duplicate or shadow that vendored source, and `pip install -r requirements.txt`
# stays deploy-neutral. Every satquery runtime dependency is already pinned above
# (fastapi, pydantic, pydantic-settings, httpx, langgraph, rasterio->numpy, Pillow).
#
# Refresh the vendored copy from the upstream agent checkout when it changes:
#   cp -r D:\SatQuery\Agent\satquery\.  backend\satquery\   (then drop __pycache__)
# Locally, run the backend from the backend/ directory so `import satquery`
# resolves this vendored copy (uninstall any editable install: pip uninstall satquery).
